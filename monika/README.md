# MONIKA Mustard Oil

Premium frontend e-commerce storefront for the MONIKA edible oil brand.

## Stack

- Next.js 16 (App Router)
- React 19 + TypeScript
- Tailwind CSS 4
- Lucide React

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Cart and wishlist persist in `localStorage`. Checkout is a placeholder until backend and payments are added.

Replace files in `public/images/` to swap product photography.
